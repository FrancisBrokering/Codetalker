# Codetalker

Talk to your coding agents.

This prototype is a macOS Swift overlay that recreates the left-side TabTab-style notch UI with dummy app data. It starts as a slim side notch and expands into the full tab switcher when you hover over the left edge of the screen.

## Run

```sh
swift run Codetalker
```

The app runs as an accessory app and pins a borderless hover target to the left side of the primary display. Stop it from the launching terminal with `Ctrl-C`.
